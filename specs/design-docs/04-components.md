# Components

## Buttons
- **Primary:** ink background, white text, pill shape, 48px height, arrow icon on the right. Hover lifts 2px or shifts to a slightly lighter ink.
- **Secondary:** white background, ink text, 1px border, pill shape, optional play icon on the left.
- Minimum target size: 44px height.

## Navigation (header)
- Left: logo "Zayn." in serif bold, with a small accent-colored dot.
- Center: text links with a 16px sans font.
- Active link: accent-soft pill background with ink text.
- Right: "Let's Talk" primary button linking to `/contact`.
- Mobile (below md): hamburger button that opens a full-width menu. Must be keyboard operable and use `aria-expanded`.

## Pill tags and eyebrows
Small rounded label with accent-soft background and uppercase text. Used for "Hello, I'm" and section eyebrows.

## Service card
Pastel background, 24px radius, icon in a white circle (48px), title, two-line description, circular arrow button bottom-right.

## Project card
White surface, 20px-radius image on top, title, muted category line, circular arrow button bottom-right. The whole card links to the project detail page with one clear link name.

## Testimonial card
White surface, quote text, 48px circular avatar, name in bold, role in muted text, five orange stars. Stars need a text equivalent such as "Rated 5 out of 5" (visually hidden).

## Stat card
White surface, icon circle, large bold number, short muted label.

## Footer
Logo, tagline, row of links, row of social icons, copyright line. Social icons need `aria-label`.

## Icons
Use one line-icon set (for example Lucide), 20px to 24px, stroke width consistent across the site.
